Changelog

Version 1.0.0 - 24 November 2026

Initial release

  • Added 3 Multiplayer Games (Blitz, Canadian Salad, Hearts)
  • 6 Solitaire Games (Beehive, FreeCell, Gimlet Rummy, Simple Simon, Spider, Sultan)
  • 4 Card Sets (Simple, Swiss Costumes, Dead or Alive, Venus Vacation)

Known Bugs and Problems

  • Canadian Salad's AI system still uses random selection. A slightly more complex version of the game AI (similar to Hearts) will come soon
  • On rare cases in Gimlet, certain melds will appear more than once (such as when a set contains 2 cards meldable in runs, the set should not count as a set)
  • Sultan's layout currently breaks on lower resolutions
  • Simple and Swiss Costumes missing large print (will be made soon)
