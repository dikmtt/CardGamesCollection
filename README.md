# Card Games Collection

A collection of several playing card games. Both solitaire and multiplayer games (against computer opponents) are available. Features various card skins (traditional, from existing decks, and themed).

## List of Games

Multiplayer Games

- Blitz/41 (4-card version of 31)
- Canadian Salad
- Hearts

Solitaire Games

- Beehive
- FreeCell
- Gimlet Rummy (Solitaire Gin Rummy)
- Simple Simon
- Spider
- Sultan
